# Logic Gates

This project contains RTL implementations of fundamental digital logic gates using Verilog HDL. 

## Gates Covered

1. AND Gate
2. OR Gate
3. NOT Gate
4. NAND Gate
5. NOR Gate
6. XOR Gate
7. XNOR Gate
